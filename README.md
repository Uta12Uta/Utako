homework1
この課題では、BFSを用いた。
まずページタイトルからページIDを取得し、出発ノードから探索を開始する。探索中に訪れたノードは visited に記録し、各ノードがどのノードから到達したかの情報を parent に保持することで、目的ノードに到達した際に経路を逆順にたどり、実際の経路（ページIDの列）を復元できるようにした。
経路が得られた後は、ページIDをタイトルに変換し、最短経路として出力するようにした。

homework2
すべてのページに初期値1のPageRankを与え、次の手順で反復的に更新を行った：
1.リンクを持たないページのPageRankは全体のページに均等に分配する。
2.各ページがリンクする先に対して、自身のPageRankの0.85を均等に分配する。
3.残りの0.15は全ページに均等に加算する。
これらの処理を繰り返し、前回とのPageRankの差が0.01未満になった時点で収束したと判断し、計算を終了した。
最終的なPageRankの値を降順に並べ替え、上位10ページを出力した。
